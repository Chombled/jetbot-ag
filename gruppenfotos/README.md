# 📸 Gruppenfotos

Hier landen die Gruppenfotos, die ihr als Abschluss der Teleoperation
mit eurem JetBot aufgenommen habt.

---

## 📤 So ladet ihr euer Foto hoch

1. Foto mit der Kamera des JetBot aufnehmen. Ein passendes Notebook
   dafür findet ihr in [`docs/`](../docs/)
2. Datei nach eurer Gruppe benennen, z. B. `gruppe_a.jpg` oder `gruppe_e.png`
3. Datei in **diesen Ordner** legen
4. Commit und Pull Request erstellen, genau wie bei eurem Code
   (siehe [`gruppen/README.md`](../gruppen/README.md))

---

## ✅ Regeln

- **Dateiname:** `gruppe_<buchstabe>.jpg`, also `gruppe_a` bis `gruppe_h`
- **Formate:** `.jpg`, `.jpeg` oder `.png`
- **Größe:** maximal ca. 5 MB pro Bild
- **Ein Foto pro Gruppe:** Wollt ihr es austauschen, überschreibt einfach eure Datei
- **Einverständnis:** Nur Fotos hochladen, mit denen alle Abgebildeten einverstanden sind
